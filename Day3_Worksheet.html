FUNCTION RULE: Each x (input) can only have ONE y (output). If an x-value repeats with different y-values → NOT a function!
🖩 SCATTERPLOT: + → table → enter data → Add regression → Read equation | Positive = both up | Negative = one up, one down | None = no pattern
