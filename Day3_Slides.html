A Function is Like a Vending Machine 🏪

🏪 VENDING
Each BUTTON gives
EXACTLY ONE item!
A1
A2
A3
B1
B2
B3

Button A1 → always chips
Button B2 → always water

Each x (input) → only ONE y (output) = FUNCTION

Dallas Example

✅ Each student ID # → one student name = FUNCTION

❌ One phone number → multiple people = NOT a function

📏 Vertical Line Test (for graphs)

"If a vertical line touches the graph more than once at any spot → NOT a function!"

Same y is OK! → {(1,5), (2,5), (3,5)} IS a function (each x is different)

Types of Association

📈 Positive
Both go UP together
📉 Negative
One up, other DOWN
🤷 None
No pattern at all

Making Predictions

"If it's 95°F in July, trace UP to the trend line — how many ice cream sales?"

→ YES, function! ✅

📋 Function Checklist:
☐ List ALL x-values
☐ Does any x REPEAT?
☐ If repeat → different y's? → NOT a function
☐ No repeats → IS a function!
⚠️ Tricky Part:
Same y is OK! → {(1,5), (2,5)} IS a function
Same x with different y's → NOT a function!
